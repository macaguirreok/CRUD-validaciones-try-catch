# CRUD - Validaciones y Manejo de Errores

Este proyecto fue creado con el objetivo de practicar y reforzar conceptos fundamentales del desarrollo de APIs REST utilizando Node.js, Express y MySQL.

A diferencia de un CRUD básico, el foco principal de este repositorio es la implementación de buenas prácticas relacionadas con la validación de datos y el manejo de errores.

## Objetivos

* Validar los datos recibidos desde el cliente.
* Verificar tipos de datos y campos obligatorios.
* Manejar errores mediante bloques `try/catch`.
* Utilizar códigos de estado HTTP adecuados.
* Evitar que la aplicación falle ante entradas incorrectas.
* Mejorar la estructura y robustez de una API REST.

## Tecnologías utilizadas

* Node.js
* Express
* MySQL
* JavaScript (ES Modules)

## Conceptos practicados

### Validaciones

* Campos obligatorios.
* Validación de IDs.
* Validación de tipos de datos.
* Validación de formatos y longitudes.

### Manejo de errores

* Bloques `try/catch`.
* Respuestas de error consistentes.
* Errores de base de datos.
* Códigos HTTP:

  * 200 OK
  * 201 Created
  * 400 Bad Request
  * 404 Not Found
  * 500 Internal Server Error

## Propósito

Este repositorio forma parte de mi proceso de repaso y consolidación de conocimientos de desarrollo backend. El objetivo no es únicamente lograr que la aplicación funcione, sino comprender y aplicar prácticas que permitan construir APIs más seguras, mantenibles y profesionales.
